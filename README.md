# Ecommerce-Analysis-using-Excel


## 📌 Project Overview

This project focuses on analyzing e-commerce sales data to gain insights into key performance metrics such as total sales, profits, number of orders, profit margins, and the performance of different product categories and subcategories. The analysis is conducted using Microsoft Excel and its built-in functions.

## 🛠 Tools & Techniques Used

- Microsoft Excel

- Excel Functions

- Pivot Tables for summarizing and visualizing data

- Conditional Formatting for highlighting key insights

- Charts & Graphs to represent sales trends

## 📊 Key Insights

- Total Sales & Profits: Calculation of revenue and profit for different time periods.

- Number of Orders: Analyzing order frequency and trends.

- Profit Margins: Understanding profitability across different products.

- Category & Subcategory Analysis: Identifying high and low-performing product segments.

## 📁 Project Files

- Ecommerce_Analysis.xlsx – Contains the raw data, all calculations and the dashboard.

- README.md – Documentation for the project.

## 🚀 How to Use

- Download the Ecommerce_Analysis.xlsx file.

- Open it in Microsoft Excel.

- Explore different sheets containing raw data, processed data, and pivot tables.
